Quick setup
How to run Gemma locally
  1. LM Studio (easiest): install from lmstudio.ai, search for gemma 3 (12B or 27B recommended, 4B works for quick drafts) and download it.
  2. Open the Developer tab, load the model, set Context length ≥ 8192, and switch Status: Running. The server listens on http://localhost:1234.
  3. Ollama alternative: run ollama pull gemma3 then keep Ollama running. Use http://localhost:11434.
  4. Press Detect models, pick your Gemma model, and you are ready.

Any OpenAI-compatible local server works (llama.cpp llama-server, Jan, KoboldCpp, vLLM).
